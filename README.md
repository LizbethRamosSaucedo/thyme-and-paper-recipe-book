# Thyme And Paper Recipe Book

1. ROL:

Actúa como un desarrollador web experto en diseño Frontend, UI/UX y Tailwind CSS, especializado en interfaces interactivas, estéticas y temáticas (vibe-coding).

2. TAREA:

Construye una aplicación web interactiva de "Recetario de Cocina Estilo Vintage", cuya interfaz principal simule la experiencia física de abrir un libro de recetas antiguo encuadernado en cuero o papel kraft. Al "abrir" la portada, se debe mostrar un índice interactivo decorado con estilo de recortes de revista antiguos (scrapbook), texturas de papel envejecido, listones de tela decorativos, pequeños detalles de botones ilustrados y sutiles ilustraciones o toques de conejos campestres estilo vintage. Al hacer clic en las secciones del índice, debe desplegar las recetas paso a paso de forma fluida y atractiva.

3. CONTEXTO:

El sitio web está dirigido a amantes de la cocina casera y la repostería que valoran la estética nostálgica, acogedora y artesanal. La página debe sentirse cálida, mágica y detallada, utilizando paletas de colores sepia, cremas, tonos madera, acentos pasteles y tipografías clásicas (serif). Debe ser totalmente responsiva y funcionar tanto en computadoras como en dispositivos móviles.

4. RESTRICCIONES:

- Utiliza componentes modernos y limpios combinados con Tailwind CSS para lograr la estética vintage (sombras suaves que simulen profundidad de papel, bordes texturizados, efectos al pasar el cursor tipo "hover" sobre los listones o recortes).

- Asegúrate de que todos los botones, pestañas del índice y enlaces de navegación sean funcionales (sin botones estáticos o inactivos).

- Incluye una sección interactiva donde los usuarios puedan filtrar recetas, buscar ingredientes o marcar recetas favoritas.

- Diseña el código de manera limpia y modular para facilitar futuras correcciones de errores si fuera necesario.
